Bộ Lạc Gà — iOS

Bản test nội bộ v26.11.18.1353 (~1,6 GB)

Cài đặt
  1. Mở trang này bằng Safari (Chrome / Zalo / Facebook không cài được).
  2. Bấm Cài đặt → Cài đặt. Ra màn hình chính chờ icon tải xong (nên dùng Wi-Fi, file ~1,6 GB).
  3. Lần đầu mở: vào Cài đặt → Cài đặt chung → VPN và quản lý thiết bị, chọn mục Chengdu Railway Bureau → Tin cậy.
  4. iOS 16 trở lên: nếu hỏi, bật Cài đặt → Quyền riêng tư và bảo mật → Chế độ nhà phát triển rồi khởi động lại máy.

Bản này là app riêng, không ghi đè bản cài bằng Sideloadly (2 icon, phải đăng nhập lại).
